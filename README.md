# DialogLearning — Демонстрация стандартных диалоговых окон PyQt5

Простое учебное настольное приложение на **Python**, демонстрирующее работу со стандартными диалоговыми окнами графической библиотеки **PyQt5**. Программа позволяет изменять параметры интерфейса в реальном времени с помощью встроенных виджетов Qt.

## Функционал

Приложение предоставляет графический интерфейс с кнопками для вызова четырех типов диалоговых окон:
* **Ввод текста (`QInputDialog`)**: Окно для ввода строки. Результат выводится в консоль.
* **Выбор цвета (`QColorDialog`)**: Окно для выбора цвета. Выбранный цвет применяется к тексту на главном экране.
* **Выбор шрифта (`QFontDialog`)**: Окно настройки шрифта (семейство, размер, стили), который применяется к тексту на экране.
* **Открытие файла (`QFileDialog`)**: Диалог выбора текстового файла. Содержимое файла считывается и отображается в текстовой области приложения.

## Требования

Для запуска проекта необходим установленный интерпретатор Python 3 и библиотека `PyQt5`.

## Установка

1. Склонируйте репозиторий или скачайте файл с кодом.
2. Установите необходимую зависимость через pip:
```bash
pip install PyQt5
```

## Запуск

Запустите скрипт с помощью команды:
```bash
python main.py
```
*(Имя файла `main.py` замените на ваше, если оно отличается).*

## Архитектура кода

Код написан с использованием объектно-ориентированного подхода (ООП):
* `Window` — основной класс графического интерфейса, наследуемый от `QMainWindow`.
* `create_button_for_test_dialog()` — инициализация и позиционирование кнопок управления.
* `create_label_for_file_text()` — настройка текстовой области (`QLabel`) для вывода информации из файлов с поддержкой автопереноса строк.
* Методы `showInputDialog`, `showColorDialog`, `showFontDialog`, `showFileDialog` обрабатывают события нажатия на соответствующие кнопки и взаимодействуют с пользователем.
